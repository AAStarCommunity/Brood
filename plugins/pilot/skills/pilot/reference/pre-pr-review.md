# 提 PR 前的强制自审（按风险分级）

**没做完这一步不许 `gh pr create`。** 后台 PR-Daemon 是最后一道关，不是第一道——把它当第一道关，
每轮要等 15–25 分钟才知道自己写错了，一个本可当场发现的问题要烧掉一整轮。

## 第 0 步：定级（先算，不要凭感觉）

```bash
# 相对目标分支的净变更行数（新增+删除，排除生成物与锁文件）
git diff --stat <integration_branch>...HEAD -- . \
  ':(exclude)dist' ':(exclude)*.lock' ':(exclude)*-lock.json' | tail -1
```

按**命中的最高一档**定级，不是取平均：

| 级别 | 判据（任一命中即归此档） | 自审要求 |
|:---|:---|:---|
| **A 高危** | 涉及**钱/资产**（支付、gas、余额、定价、合约）· **安全**（认证、授权、密钥、签名、权限、注入面）· **删除或迁移数据** · **改动强制层本身**（git-guard / hook / CI 守卫 / 门禁脚本） | **Codex 对抗挑战 ≥3 轮** |
| **B 复杂** | 净变更 **>100 行**（按上面的命令）· 或跨 ≥3 个模块 · 或改了并发/重试/状态机 | **Codex 对抗挑战 ≥3 轮** |
| **C 常规** | 有可执行代码，但既非 A 也非 B | **Codex 挑战 1 轮** |
| **D 纯文档** | 变更**只**含 `.md` / 注释 / 文案，**无任何可执行代码或配置**（`.yml`/`.json`/`.sh`/脚本改动**不算**纯文档） | Sonnet 自审 1 轮 |

> **归档存疑时往高处归。** 定级是你自己做的，没人复核；往低处归省下的十几分钟，
> 抵不上一个上线事故。**A 档的判据优先于行数**——3 行的密钥处理改动仍是 A。

## A / B / C：Codex 对抗挑战

用 `/codex:rescue`（或 `mcp__codex__codex`）。**每轮换一个视角**，别重复问同一句话：

| 轮次 | 视角 | 问什么 |
|:---|:---|:---|
| 1 | **正确性** | 边界值、空/零/负、并发与重入、错误路径、部分失败后的状态 |
| 2 | **对抗** | 「**这段代码在生产环境会怎么坏？**」要求它举出**具体的触发输入/时序**，而不是泛泛的担忧 |
| 3 | **失效模式** | A 档问安全（越权、伪造、密钥泄漏、签名可绕过）与资金（多花/少收/重复扣/精度）；B 档问「**改了 X，哪些依赖 X 的地方没同步改**」（跨层一致性——历次评审最常抓到的就是这类） |

规则：

1. **每轮把它提的问题当真**：能复现就修，修完**重跑自测**再进下一轮。
2. **不盲从**：判定为「它缺业务上下文判错了」就写下理由（这条理由要进 PR 描述），不改代码。
3. **A/B 档必须跑满 3 轮**，即使第 1 轮说「没问题」——第 1 轮没问题往往意味着提问角度不对，换视角再来。
4. **第 3 轮仍有阻塞问题 → 不许提 PR**，修完从第 1 轮重来。

**这一步做完的收益是可验证的**：本仓库 #35 的 fail-open 门禁、#22 的构建污染，
都是提 PR 之后才被 daemon 抓到的——它们在「视角 2 / 视角 3」下当场就会暴露。

## D：Sonnet 自审

纯文档也要过一遍，只是不必上 Codex：

- 所有**事实性断言**逐条对照真实代码/配置核实（版本号、路径、命令、行为描述）；
- 改的这份文档描述的行为，**代码里真的是那样吗**；
- 同一件事在**别处还有没有写**（README / SKILL.md / plugin.json / marketplace.json / 注释）——
  历次评审里「只改了一处、另一处自相矛盾」是最高频的文档缺陷。

## PR 描述里必须带的自审标签

放在 PR body 开头，让评审者一眼知道这份 diff 经过了什么：

```markdown
<!-- pilot:self-review -->
**自审等级**：B（复杂 · 净变更 187 行 / 跨 4 个模块）
**方式**：Codex 对抗挑战 3 轮
- 轮1 正确性 → 2 个问题（空数组越界、重试未退避），已修
- 轮2 对抗   → 1 个问题（并发写同一文件），已修
- 轮3 跨层   → 无阻塞;提出的「配置项该文档化」判为非阻塞,已记入 followups FU-12
**自测**：`pnpm test` 全绿 · `pnpm build` 通过 · 门禁断言 8/8
```

D 档同样要贴，写明 `**自审等级**：D（纯文档）· **方式**：Sonnet 自审 1 轮`。

**没有这个标签的 PR 视为没做自审**——评审者据此判断该投入多少精力，
谎报等级比不写更糟。
