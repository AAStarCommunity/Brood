# MARKET_VALUE.md — 市场与价值评估

> "中小网站需要加密支付么？" — 这是错的问题。
> 正确问题是："**已经想收加密的中小网站**，为什么没收？"

---

## 1. 目标客户画像（不要做错）

### 1.1 在做什么的人

| 标签 | 典型场景 | 月收入区间 (USD) | 痛点 |
|:---|:---|:---:|:---|
| **加密内容创作者** | Substack/Mirror 写手、独立 Newsletter、Patreon 替代 | 100–10k | Stripe 拒收、Coinbase Commerce 国家限制 |
| **数字商品独立站** | 电子书、字体、PSD/Figma 模板、AI prompt 包、StableDiffusion model | 500–20k | Stripe 风控冻结、PayPal 180 天审查 |
| **小型 SaaS / API 服务** | 一人创业的 LLM 中间件、爬虫 API、图床、邮件验证 | 1k–50k | 法币通道月费 + KYC 太重 |
| **开源项目打赏 / 赞助** | GitHub Sponsors 替代、Bountysource 替代 | 0–5k | GitHub Sponsors 抽 0%但要 Stripe Connect |
| **NFT/数字艺术家** | 个人作品集站、不愿用 OpenSea | 100–10k | 已在加密圈，痛恨平台抽成 |
| **小型电商 / 联盟营销** | 跨境独立站、Dropshipping、Shopify Lite | 500–30k | 国别支付通道贵且不稳 |
| **本地服务 + 远程客户** | 翻译、咨询、设计、家教 | 200–10k | 跨境收款手续费高 |

### 1.2 共同特征（FangPay 的 ICP）

✅ 客户已经持有或愿意持有加密
✅ 月流水 < 50k USD（再大会优先找 Stripe/Coinbase Commerce 谈费率）
✅ 1-3 人团队，**没有工程师**做合约对接
✅ 用 Webflow/Framer/Vercel/Notion-Sites/独立 WordPress
✅ 不需要发票 / 不强制要月度对账单
✅ 厌恶平台风控（被 Stripe 冻过、被 PP 限过）

### 1.3 不是目标客户

❌ 月流水 > 100k USD 的成熟电商（会自己集成 Coinbase Commerce / Circle）
❌ 需要发票 / 月度结算 / 强对账的 B2B SaaS
❌ 监管敏感行业（赌博、成人内容、武器）— 这些不该用，也不能用
❌ 完全不懂加密的传统商家（他们需要的是稳定币 onramp，不是 FangPay）

## 3. 价值主张（三句话）

### 给商家
> "给我一个邮箱和钱包地址，我给你一个能直接收 USDC/USDT 的页面。前 10 笔我请客，第 11 笔起买点 aPNTs 抵 gas 费就行。"

### 给用户（买家）
> "不用提前买 ETH，签个名就付完了。钱直接到商家钱包，不经我们手。"

### 给监管/法务
> "我们不接触客户资金，不持有牌照需求。我们卖的是 gas 代付 + 签名中继，类似 Cloudflare 的边缘网络服务，不是 PayPal 的支付服务。"

## 4. TAM 粗略推算（保守版）

### 4.1 商家端
- **加密原生独立创作者 + 小独立站**（不依赖 Stripe）：全球估 **50万–100万**（参考 Mirror.xyz 活跃用户 + GitHub Sponsors + Patreon 加密占比反推）
- **会想用加密收款的传统小型 SaaS / 独立站**：全球估 **200万–500万**
- 合计 **TAM ~250万–600万商家**

### 4.2 单商家年收入估算
- 平均月流水 2k USD × 12 = 24k USD/年
- 平均月交易笔数 50 笔 × 12 = **600 笔/年**
- FangPay 收入（aPNTs 计费）：
  - 假设 600 笔 - 10 笔免费 = 590 笔付费
  - 平均每笔 gas 服务费 1 USD（含 gas + 30% 毛利）
  - = **590 USD/商家/年**

### 4.3 总市场天花板（5 年看）
- 渗透率 1%（5 万商家） × 590 USD = **~3000 万 USD/年** → 早期可活
- 渗透率 5%（25 万商家） × 590 USD = **~1.5 亿 USD/年** → 健康规模
- 渗透率 10%（50 万商家） × 590 USD = **~3 亿 USD/年** → 行业标准品

> 这个数字对单独的 startup 不够大（VC 看不上），但作为 **Mycelium 生态的"流量入口 + aPNTs 燃料消耗器"** 价值远超本身收入。

## 6. 与 Mycelium 协议层的对齐

| Mycelium 维度 | FangPay 体现 |
|:---|:---|
| **数字公共物品** | Apache 2.0 全开源，商家可自部署 Relay |
| **零数据剥削** | 平台只见 hash 和 gas 计费，看不到商品/客户信息 |
| **资金主权** | 商家自己持私钥，平台无法冻结/挪用 |
| **意义经济** | 让独立创作者跨境收款、不依赖平台 |
| **两层成本** | 运营成本由 aPNTs 计费覆盖；规模化由 HyperCapital 承担 |
| **协议层不抽租** | 与 Stripe/PayPal 不同，FangPay **不抽交易金额 %**，只收 gas 服务费 |

## 7. 一句话结论

> **市场是真实的（不大但真实），价值是清晰的（去掉资金过手 + gas 摩擦），技术是现成的（AAStar 全栈现成），合规是关键风险（必须先做法务）。**
>
> 建议优先级：**法务确认 → Sepolia demo → 5 个种子商家试点 → aPNTs 计费跑通 → 决定是否大规模做。**
