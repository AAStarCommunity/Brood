## 1. Lite 版范围声明（当下重心）

> **Lite 版只做一件事**：让中小商家在 30 分钟内拥有一个**能收 USDC 且不让客户付 gas 的收款页**。
>
> 任何"超出此范围"的疑虑，**Lite 版回答统一是"v1.5/v2 解决"**，不在 Lite 版承诺。

### 1.1 Lite 版包含（必做）

| 维度 | Lite 范围 |
|:---|:---|
| 支付路径 | **Path A**（EOA + USDC + EIP-3009）+ **Path F**（Relay 故障兜底自付） |
| 支持代币 | 仅 **USDC**（Circle Native，不要桥接版） |
| 支持链 | **Base + Arbitrum**（推荐 Base） |
| 商家集成 | 单一收款页（`pay.xxxx/<slug>`）+ 一行 `<script>` 嵌入 |
| 商家功能 | 收款 + 链上 hash 凭证 + 简单订单列表 |
| 商业模型 | 协议层 gas fee 10% 抽成（aPNTs 抵扣）|
| 商业服务 | 包 A：Cloudflare onboarding（$99-$299 一次） |

### 1.2 Lite 版不做（明确缓）

| 维度 | 推迟到 |
|:---|:---|
| USDT 支持（Path C） | **v1.5** |
| CEX 提币引导（Path E） | **v1.5** |
| 智能账户 Path B | **v1.5**（Coinbase Smart Wallet 普及后再做） |
| 原生币 ETH Path D | **v2** |
| 跨链桥 Path G | **v2** |
| 多商品 / 购物车 | **v2** |
| NFT 凭证 / 订阅 / 退款 / 积分 | **v2** |
| Dashboard 多页面 | **v2** |
| AI Skill 配置 | **v2 或不做** |
| 商业服务包 B/C（月度运维 / 企业定制） | **v1.5** |

### 1.3 Lite 版的 4 周交付节奏（粗排）

| 周 | 交付 |
|:---:|:---|
| W1 | slug registry 合约 + Cloudflare Worker Relay 模板 |
| W2 | 收款页 SPA（pay.fangpay.io）+ Path A 端到端跑通 |
| W3 | 商业服务包 A 流程文档 + Cloudflare onboarding 视频 |
| W4 | 5 个种子商家试点 + 收集反馈 |

> Lite 版任何**超出 4 周**的工作都需重新讨论是否纳入。

## 5. HyperCapital 商业服务包 A：完整 Onboarding 流程

> 这是 Lite 版**唯一交付**的商业服务包。一对一辅导，30-60 分钟完成全部配置。

### 5.1 服务范围

| 项目 | 含 | 不含 |
|:---|:---:|:---:|
| Cloudflare 账号开通 | ✓ | 客户信用卡绑定（客户自己做） |
| Cloudflare API token 建立 | ✓ | token 保管（客户自己存） |
| 自动化部署 FangPay Relay Worker | ✓ | — |
| 自动化部署收款页 Pages | ✓ | — |
| 域名 DNS 配置（可选） | ✓ | 域名购买（客户自己） |
| Relay EOA 私钥生成 + 保管教学 | ✓ | 私钥代管（绝对不） |
| Relay EOA 首次充值 0.05 ETH 教学 | ✓ | 代充值 |
| 5 笔测试支付 | ✓ | — |
| 后续 1 周邮件答疑 | ✓ | 后续运维（要包 B） |

### 5.2 标准流程（60 分钟版）

```
┌────────────────────────────────────────────────────────────────┐
│  T+0 min ─ 客户购买服务包 A，付款后预约 Zoom/腾讯会议             │
├────────────────────────────────────────────────────────────────┤
│  T+5 min ─ 视频接通                                              │
│  ─ HyperCapital 工程师确认客户身份 + 需求                          │
│  ─ 共享屏幕，开始操作                                              │
├────────────────────────────────────────────────────────────────┤
│  T+10 min ─ Cloudflare 账号开通                                  │
│  ─ 客户打开 https://dash.cloudflare.com/sign-up                  │
│  ─ 邮箱注册 + 验证                                                │
│  ─ 跳过付费方案（用免费层）                                       │
│  ─ 工程师指导，但**客户自己输入密码、点击按钮**                     │
├────────────────────────────────────────────────────────────────┤
│  T+20 min ─ Cloudflare API token 建立                            │
│  ─ 客户访问 https://dash.cloudflare.com/profile/api-tokens       │
│  ─ Create Token → Custom token                                   │
│  ─ 权限**最小化**：                                               │
│        Account → Workers Scripts → Edit                          │
│        Account → Pages → Edit                                    │
│        Zone → DNS → Edit（仅在客户用自有域名时）                   │
│  ─ TTL：90 天（强制轮换）                                          │
│  ─ IP 限制：HyperCapital 工程师 IP（可选，更安全）                 │
│  ─ 客户**自己复制** token，存到自己的 1Password / Bitwarden        │
│  ─ 通过加密 chat（Signal/Element）临时传 token 给工程师            │
├────────────────────────────────────────────────────────────────┤
│  T+30 min ─ 工程师用 token 跑自动化部署脚本                        │
│  ─ 在工程师本地（或临时容器）跑：                                  │
│        export CF_API_TOKEN=<客户的 token>                         │
│        bash deploy-fangpay.sh --merchant <slug> --chain base     │
│  ─ 脚本动作（全公开 + 客户可监督）：                               │
│        1. wrangler 部署 fangpay-relay Worker 到客户账号           │
│        2. wrangler 部署 fangpay-page Pages 到客户账号             │
│        3. wrangler kv 创建 SLUG_REGISTRY namespace                │
│        4. wrangler secret put RELAY_PRIVATE_KEY（客户提供）       │
│        5. wrangler secret put ALCHEMY_KEY（HyperCapital 默认）    │
│        6. 配置 *.pages.dev 子域名（或客户自有域名 CNAME）          │
│        7. cURL 探针，确认部署成功                                  │
├────────────────────────────────────────────────────────────────┤
│  T+45 min ─ Relay EOA 私钥生成 + 首次充值                         │
│  ─ 工程师指导客户用 cast wallet new 生成 EOA                       │
│  ─ 客户**自己保管**助记词（写纸上 + 1Password）                    │
│  ─ 客户从交易所 / 现有钱包转 0.05 ETH（Base 链）到 Relay EOA       │
│  ─ 测试余额检测                                                    │
├────────────────────────────────────────────────────────────────┤
│  T+55 min ─ 5 笔测试支付                                          │
│  ─ 工程师用测试 USDC（如 Base Sepolia）跑 5 笔                     │
│  ─ 监控 Relay Worker 日志（客户屏幕共享）                          │
│  ─ 确认链上 5 笔 tx 成功                                          │
├────────────────────────────────────────────────────────────────┤
│  T+60 min ─ 客户撤销 / 轮换工程师 IP token（可选）                 │
│  ─ 客户重新建一个**只有客户自己用**的 token                        │
│  ─ 删除工程师用过的 token                                          │
│  ─ 客户从此完全自主                                                │
├────────────────────────────────────────────────────────────────┤
│  T+0 ~ +7 天 ─ 邮件答疑                                            │
│  ─ 客户可以问任何使用问题                                          │
│  ─ 超过 1 周后再问 → 升级到包 B 月度运维                            │
└────────────────────────────────────────────────────────────────┘
```

### 5.3 安全纪律（HyperCapital 必须遵守）

| 项 | 规则 |
|:---|:---|
| Token 保管 | 工程师本地用完即删，**不入产品系统、不入日志、不入 git** |
| Token 传输 | 仅经 Signal / Element / Matrix E2EE chat，禁用邮件 / Slack / WhatsApp |
| 屏幕共享 | 全程客户共享自己屏幕，工程师**几乎不输入敏感字段**（除非客户授权） |
| 私钥 | **绝对**不接触客户 Relay EOA 私钥；如客户问能不能代管，明确拒绝 |
| 客户审计 | 部署脚本全部开源，客户可在 Cloudflare Audit Log 验证每个动作 |
| 客户撤销 | 服务结束 24 小时内提醒客户撤销 / 轮换 token |
| 事后报告 | 邮件发送本次部署的 commit hash + Worker version + Pages URL，客户存档 |
