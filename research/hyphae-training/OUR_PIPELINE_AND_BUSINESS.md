## 6. 关键挑战与应对

| 挑战 | 应对 |
|:---|:---|
| **H100 CC GPU 自建成本高** | v1 借力 Phala / Spheron / Azure CC；v2+ 自建小集群 |
| **客户对 TEE 不信任** | 提供 NVIDIA Remote Attestation 证书 + 律师函解释 |
| **多 GPU TEE 不成熟** | v1 仅支持单 GPU 训练（覆盖 ≤ 30B QLoRA） |
| **HyperCapital 工程师不够** | 培养 5-10 人队伍 + 标准化 SOP + 自动化脚本 |
| **联邦学习冷启动难** | 先与 1-2 个行业协会合作（律师协会 / 医师协会）批量招商 |
| **客户数据准备能力弱** | 提供傻瓜化数据清洗 GUI（v1.5 推出） |
