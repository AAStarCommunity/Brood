## 1. 中国积分商城市场现状（市场已饱和但有结构性裂缝）

### 1.1 主流玩家分类

| 类型 | 代表 | 模式 | 抽成 |
|:---|:---|:---|:---:|
| **平台型 SaaS** | 福利易、好福利、必盈福利、来易等 | 商家入驻平台，平台供货 | **服务费 5-15%** + 商品差价 5-30% |
| **互联网巨头自营** | 京东企业购、阿里 1688 福利 | 平台自营商城，商家充值 | **服务费 3-8%** + 商品差价 |
| **银行积分通兑** | 招行掌上生活、中信通付 | 银行积分换商城商品 | 银行自营 |
| **垂直行业** | 携程会员、平安万里通 | 集团内部通兑 | 集团自营 |
| **DIY 系统** | 商家自己开发 / 用 SaaS 工具（如有赞、微盟） | 商家自建商城 | 工具费 + 流量推广费 |

### 1.2 商家入驻这些平台的真实痛点

> 来源：商家访谈 / 创业社群 / 36 氪报道 / 知乎 + 实际签约合同分析

| # | 痛点 | 真实程度 | 当前商家应对 |
|:---:|:---|:---:|:---|
| **P1** | **抽成高** —— 服务费 5-15% + 商品差价 5-30% | 高 | 默默承受 |
| **P2** | **客户数据被锁** —— 用户在商城买了什么、什么时候买，平台拿走，商家拿不到 | 高 | 抱怨但无奈 |
| **P3** | **商品有限** —— 平台供货商有限，商家想给客户的特定商品平台不卖 | 中 | 退出，自己做 |
| **P4** | **预付资金占用** —— 平台要求商家先充值积分库 | 高 | 现金流压力 |
| **P5** | **不透明** —— 平台单方调商品价格、调汇率、削积分 | 高 | 怀疑被薅 |
| **P6** | **无品牌** —— 客户进了平台商城就看到平台 logo，商家品牌淡化 | 中 | 接受 |
| **P7** | **客户被截流** —— 平台借机推自己其他业务，商家客户被引走 | 中 | 难以察觉 |
| **P8** | **不能跨平台** —— 与其他平台积分互不相通 | 中 | 多平台分散运营 |
| **P9** | **不能跨境** —— 海外华人客户用不了 | 低（但有跨境业务的商家强需求） | 放弃海外客户的积分 |
| **P10** | **被绑架** —— 想换平台 → 历史积分作废 / 数据丢失 | 高 | 不敢换 |
| **P11** | **规则突变** —— 平台单方面改服务费、改规则 | 高 | 只能接受 |

### 1.3 商家的"未说出口"心声

> "其实我也想自己做积分商城，但没人会开发。给福利易交 10% 算了。"
> "客户在京东企业购买了什么我都看不到，但客户的钱是从我账户走的。"
> "上次福利易突然把服务费从 5% 涨到 8%，我有什么办法？"
> "我想给客户的礼品里加一个我自己的品牌周边，福利易说不支持，让我用他们标准 SKU。"
> "我们做跨境贸易的，海外客户的积分根本没法用，相当于浪费了一个营销渠道。"

→ **这就是市场结构性裂缝**。

## 2. 我们的 7 大差异化（按商家感知强度排序）

### 差异化 1 — **抽成模型革命**：从抽商品额到只抽 gas

| 维度 | 传统积分商城 | FangPay Loyalty |
|:---|:---|:---|
| 服务费 | 积分流通额 5-15% | **0%** |
| 商品差价 | 5-30% | **0%**（商家自己定供货价）|
| 平台真正收入 | 商家流水抽成 | **链上 gas 费 10% 加价**（< 1% 流水）|
| 例子 | 100 万积分流通 → 收 10 万元 | 100 万积分流通 → 收 1000 元 gas 服务费 |

**商家得到**：每年省下 5-15% 流通额 → 中型商家 10-50 万人民币 / 年

**核心**：我们卖的是技术 + gas 代付服务，**不卖积分流通本身**。这是 FangPay "不抽支付金额 %" 哲学在积分场景的延伸。

### 差异化 2 — **数据主权 + 链上账本**（这是真正杀伤性）

#### 传统平台数据流：
```
客户买商品 → 数据进入平台 → 商家看不到细节
   ↓
平台用这些数据做精准推荐 / 卖广告 / 引流到自家其他业务
   ↓
商家被平台"白嫖" → 客户慢慢变成平台的客户，不是商家的
```

#### 我们的数据流：
```
客户买商品 → 链上记录（hash + 商家 ID + 商品 ID + 时间）
   ↓
中国端镜像 DB 商家可随时下载（手机号 → 商品 → 时间）
   ↓
商家拿到完整客户行为数据 → 自主营销 / 复购
   ↓
平台拿不到（链上是脱敏的，DB 是商家自己的）
```

**商家得到**：
1. ✅ **客户购买行为数据 100% 归商家**
2. ✅ **链上账本作为商家的"承诺凭证"** —— 商家可对客户证明"我从未偷偷削减你的积分"
3. ✅ **不被截流** —— 平台没有客户联系方式，不能引流到其他业务

**真实场景**：
> 卖咖啡的商家给客户发 1000 积分。3 个月后客户来兑换。
> 传统平台：商家不知道这客户还买过别的什么，不能针对性营销。
> 我们：商家看到客户最近 30 天还兑换过 2 杯拿铁 + 1 块蛋糕 → 推送"加 50 积分送奶油"。

### 差异化 3 — **链上账本作为商家信任凭证**（仅此一家）

#### 传统积分商城的信任问题：

> 用户视角："这家积分商城会不会突然贬值我的积分？规则会不会偷偷改？"
> 这是中国客户对会员积分**普遍不信任**的根本原因（参考 ofo 押金 / 各种会员卡贬值事件）。

#### 我们的解法：

链上账本 = 不可篡改的**商家承诺记录**：
- 商家发出 X 积分 → 链上 emit Event
- 商家承诺"1 积分 = 1 元购买力" → 写入合约
- 商家如果想变规则 → 链上需要新合约，**用户随时可查历史**

```
商家页面 UI：
┌─────────────────────────────────────────────┐
│  我们的承诺 (链上不可篡改)                     │
│  ─────────────────────                       │
│  · 1 积分 = 1 人民币购买力                    │
│  · 时效: 365 天                              │
│  · 商家承诺: 永不单方面降低积分价值              │
│  · 链上查证: [跳 Etherscan]                  │
│  · 历史规则变更: 0 次（自 2026 年 X 月起）     │
└─────────────────────────────────────────────┘
```

**商家得到**：
1. ✅ **对客户的可信承诺凭证**（增加客户信任 → 提升复购）
2. ✅ **市场差异化卖点**："看，我们用区块链，承诺不可改"
3. ✅ **应对监管** —— 监管可第三方核验

**真实场景**：
> 高端餐厅给会员发积分。客户最大顾虑："餐厅倒闭了我的积分怎么办？"
> 传统平台：商家也没办法，平台也不担保。
> 我们：链上承诺 + 商家可承诺"如倒闭，提前 30 天通知用户兑换"。倒闭也不能改链上规则。

### 差异化 5 — **跨境天然支持**

#### 传统平台：
- 福利易 / 京东企业购：**只服务中国大陆**
- 海外商家 / 海外客户：**完全用不了**

#### 我们的双层架构天然解决：

| 商家类型 | 用户类型 | 我们的支持 |
|:---|:---|:---|
| 中国商家 | 中国客户 | cn.platform.com 普通商城 |
| 中国商家 | 海外华人客户 | 中国商家**单独**给海外用户的礼品采购（小额 B2B 跨境，可走个人邮政清关） |
| 海外商家 | 中国客户 | 中国商家入驻海外商城 → 海外用户兑换中国实体商品 |
| 海外商家 | 海外客户 | global.platform.com 链上原生 |

**商家得到**：
1. ✅ **跨境业务客户可被纳入积分体系**（海外华人客户来淘宝消费 → 给积分）
2. ✅ **跨境员工福利**（外贸公司给海外团队员工发福利）
3. ✅ **海外华人留学生市场**（这是个被忽略的大池）

**真实场景**：
> 上海某高端化妆品独立站，30% 客户在海外（华人留学生 + 二代华裔）。
> 传统积分商城：海外客户的消费不能给积分，丧失 30% 复购触发点。
> 我们：海外客户也能发积分 + 在 global 端兑换 + 中国端兑换跨境发货。

### 差异化 6 — **联盟联合营销（非积分互换，是品牌互推）**

> ⚠️ 严格不做"跨家积分直接互换"（避免触发预付卡），但**可做联盟内联合营销**。

#### 联盟内可做：
1. **联合品牌曝光** —— A 家商城首页显示"联盟伙伴 B 家本月活动"
2. **联合促销** —— 满 1000 积分送 B 家优惠券（不是积分互换）
3. **跨家会员推荐** —— A 家客户推荐 B 家入会 → A 家得积分回馈
4. **联盟会员等级互认** —— A 家金卡 = B 家自动银卡（信用互认，非积分）
5. **联盟内统一支付** —— FangPay + Loyalty 双工具协同

**商家得到**：
1. ✅ **小商家也能有"联盟"** —— 大商家有自己生态（如阿里系联盟），小商家没有
2. ✅ **跨品牌流量** —— 通过联盟伙伴推荐获得新客
3. ✅ **降低单店运营成本** —— 共享营销资源

**真实场景**：
> 同一个商圈：咖啡店 + 健身房 + 书店 + 美甲店。
> 传统方案：各自做积分，互不相干。
> 我们：联盟内联合卡 —— 在咖啡店消费 → 在健身房得 20% 折扣推送 → 在书店积分翻倍。

### 差异化 7 — **开源 + 可自部署 + 不被绑架**

#### 传统平台：
- 商家用 福利易 3 年，已发出 100 万积分

- 商家随时可 fork 自己部署
- 数据**随时全量导出**（CSV / SQL / 链上记录）
- HyperCapital 可提供"迁移服务"（如果商家想脱离 HyperCapital 自己运维）
- 平台**不能绑架**商家

**商家得到**：

2. ✅ **议价权** —— 平台不敢乱涨价（你随时可走 → 平台必须保持竞争力）
3. ✅ **长期安心** —— 平台倒闭也不影响（自己有完整代码 + 数据）

**核心**：这与传统 SaaS 的"vendor lock-in"哲学**根本对立**。

### 6.2 商家可能的"伪需求"识别

⚠️ **如果商家提以下需求，要么婉拒，要么解释为何不做**：

- "我想发可在二级市场流通的积分" → 拒绝（监管红线）
- "我想让积分能换现金" → 拒绝（支付牌照）
- "我想让客户之间转让积分" → 拒绝（支付牌照）
- "我想给客户发的积分能升值" → 拒绝（证券）
- "我想搞个空投" → 拒绝（违反 9·4 公告）

我们做的是**严格在合规边界内**的工具，不为商家"创新违法"。

### 6.3 销售压力测试

> 与福利易 / 京东企业购等成熟平台正面竞争 → 我们的真实胜算？

| 维度 | 福利易等成熟平台 | 我们 |
|:---|:---|:---|
| 品牌信任 | 已有 + 成熟 | ❌ 新 |
| 客户量级 | 百万级商家 | ❌ 0 起步 |
| 商品供应链 | 成熟 + 全 | ❌ 需自建 |
| 价格 | 5-15% 抽成 | ✅ < 1% gas |
| 数据归属 | 平台 | ✅ 商家 |
| 品牌主权 | 平台 | ✅ 商家 |
| 跨境 | 不支持 | ✅ 原生支持 |
| 信任凭证 | 平台担保 | ✅ 链上承诺 |
| 不被绑架 | 锁死 | ✅ 开源可走 |

**胜算判断**：
- **不能正面打**（品牌 / 供应链 / 量级都输）
- **必须找结构性裂缝**：
  - **裂缝 1**：被福利易等抽成抽到痛的中小商家
  - **裂缝 2**：被平台数据锁怕了的品牌商家
  - **裂缝 3**：有跨境业务需求的商家
  - **裂缝 4**：极度重视品牌主权的独立商家
  - **裂缝 5**：加密圈 / Web3 商家

→ **不要试图替代福利易，做福利易做不了的 5% 商家**。这 5% 中国估有 5-50 万 → 足够支撑业务。
