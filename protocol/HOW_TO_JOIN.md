# 如何加入 Mycelium Protocol

## 三种参与方式

### 1. 建设者（Builder）
你有一个组织或产品，希望作为生态参与者加入协议网络。

**流程**:
1. Fork `github.com/jhfnetboy/Brood`
2. 复制 `orgs/template/PROFILE.md` → `orgs/your-org-id/PROFILE.md`
3. 填写组织名片（至少填写 `org_id`, `org_name`, `layer`, `provides`）
4. 提 PR，标题：`chore: add [org-name] to Mycelium Protocol`
5. 维护者 review，合并后你的组织正式出现在生态图谱中

**最低要求**: 一个 `PROFILE.md` 文件，其余（仓库注册、跨组织依赖）可渐进补充。

### 2. 用户 / 生态参与者（User）
使用生态内产品和服务。

- 使用 **AirAccount**: 无密码 Web3 账户
- 使用 **SuperPaymaster**: Gasless 交易
- 使用 **Cos72**: 社区工具

访问各组织官网或 GitHub 了解接入方式。

### 3. 生态伙伴（Ecosystem Partner）
学术机构、投资方、媒体、其他协议——希望与生态建立连接但暂不贡献代码。

联系: 通过 MushroomDAO 官方渠道

---

## 透明原则

加入协议意味着：
- 你的组织使命、能力、路线图在生态内**公开透明**
- 你的仓库活跃状态会被 `sync-all-repos` 周期性更新
- 你可以选择公开路线图的粒度，但基本信息对生态成员可见
