# Mycelium Protocol / MushroomDAO 组织名片

## 我们是谁

Mycelium Protocol 是本生态的**协议层**，也是 BroodBrain 所服务的核心协议。

MushroomDAO 是协议的治理组织，致力于"在区块链上构建超越 DeFi 的新经济范式"。

## 核心理念

**菌丝网络**：不是层级制，而是去中心化协作网络。每个加入的组织既是建设者也是生态参与者。

- 协议使命：构建让合作更快、更多样的去中心化网络
- 探索方向：dKMS（分布式密钥管理）、新合作经济模型
